## 🔧 Troubleshooting

**The download page does not open.** Check your internet connection, then try a different browser. If the page still does not load, wait a few minutes and try again.

**The download stops before finishing.** Cancel the download and start it again from the same link. Avoid pausing and resuming very large downloads if your connection is unstable.

**The copy is very slow.** Close other programs that use the connection or the drive. Large files naturally take longer, so let the copy finish without interrupting it.

**The game does not appear on the PS Vita.** Reconnect the device and verify that the files are in the correct folder with the correct names. Compare your layout with the download page instructions.

**The game closes immediately.** Copy the release files again, replacing what is already on the device. Make sure the copy completes fully before you launch.

**Something changed after an update.** Download the newest release from the same link and replace the older files on your device. Mixing files from different releases can cause problems.
